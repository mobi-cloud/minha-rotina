# minha rotina

App pessoal de pós-treino (rolo, mobilidade e alongamento) e diário de jogos.

- Site: https://mobi-cloud.github.io/minha-rotina/
- Dados e fotos: Supabase (projeto ficha-ejercicios, tabela `minha_rotina`, bucket `minha-rotina-fotos`), protegidos por login.
- Para instalar no iPhone: abrir o site no Safari → compartilhar → "Adicionar à Tela de Início" com "Abrir como app web" ligado.
